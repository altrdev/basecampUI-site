# basecampUI

Interfaccia custom per [Home Assistant](https://www.home-assistant.io/): una dashboard pensata come "campo base" della casa, con tutto ciò che serve a colpo d'occhio.

> Questo repository contiene il **sito di presentazione e la documentazione** di basecampUI.

## Contenuti

- [Panoramica](docs/overview.md): obiettivi e filosofia del design
- [Installazione](docs/installation.md): come configurarla nella tua istanza di Home Assistant
- [Personalizzazione](docs/customization.md): temi, card e layout
- Screenshot in `assets/screenshots/`
