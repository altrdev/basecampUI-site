# Basecamp UI — website

Marketing site for **Basecamp**, a custom [Home Assistant](https://www.home-assistant.io/) interface (a `panel_custom` in vanilla JS, designed for the wall tablet).

Static site, English and Italian, no build step: open `index.html`, or enable GitHub Pages on `main`.

- `index.html`, `assets/style.css`, `assets/app.js`: the page, the styles and the EN/IT switcher
- `assets/screens/`: screenshots of the real interface, rendered with a fictional demo home (no personal data)
