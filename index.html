Basecamp UI

Una dashboard di casa per Home Assistant, senza Lovelace. HTML, CSS e JavaScript vanilla, pensata per il tablet a muro.

Principi

Nessun build step

Un web component registrato come panel_custom, senza framework.

Costruita dai registri

Aree, dispositivi ed etichette di HA definiscono la UI; la configurazione dice solo il resto.

Sola lettura di default

Comandi in un elenco chiuso; le azioni delicate chiedono pressione prolungata o codice.

Tablet prima di tutto

Layout 1280×800, tema scuro, numeri grandi, target touch generosi.

Cosa fa

Casa

Zone, luci, tapparelle, clima e qualità dell'aria.

Energia e meteo

Flussi solari, storico, bolletta stimata, stazione meteo.

Sicurezza

Allarme, telecamere, accessi e citofono.

Funzioni

Robot, auto elettrica, musica, elettrodomestici, rack e storico.

Documentazione

Panoramica · Funzionalità · Architettura · Installazione · Personalizzazione
